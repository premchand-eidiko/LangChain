# Few-Shot Templates

Few-shot prompting gives a model examples of the expected input and output
before the real request. The examples teach a pattern without hard-coding every
possible answer.

This lesson shows both text few-shot prompting and chat few-shot messages. The
examples are intentionally small and use no model API.

## Run

```bash
python3 main.py
```

## Practice

Add an example for another language or framework. Observe how changing the
examples changes the instruction sent to the model.
